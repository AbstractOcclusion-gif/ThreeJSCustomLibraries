# Fish models

`webaquarium-species.json` — 11 species (body mesh, fin pivots, embedded textures) authored by Abstract Occlusion for the
WebAquarium project and exported by its `fish-import/install.py`. Own work, MIT like the rest of this repo.
`createFishFlock({modelsUrl})` loads this file by default; pass your own `modelsUrl` (same JSON layout) or `models` (parsed) to replace it.
