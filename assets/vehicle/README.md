# Vehicle demo assets

`kenney-suv.glb` — the SUV from Car Kit 3.1 by Kenney (https://kenney.nl/assets/car-kit), licensed CC0
(http://creativecommons.org/publicdomain/zero/1.0/). The kit's shared `colormap.png` texture is embedded in the file
so it loads on its own; geometry and node names (`body`, `wheel-front-left`, ...) are unchanged. Used by the vehicle
demo (`bench/demo-vehicle/`), which scales it and measures the wheel layout at load.
