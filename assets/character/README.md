# Character demo assets

Third-party files used by the character demo (`bench/outdoor/`). Neither is covered by this repo's MIT licence.

`mixamo-bot-lowpoly.glb` — "Mixamo bot character (Lowpoly)" by Rzyas (https://sketchfab.com/rzyas), licensed CC-BY-4.0
(http://creativecommons.org/licenses/by/4.0/). Source:
https://sketchfab.com/3d-models/mixamo-bot-character-lowpoly-c0c4d8c54d394e50821c193bd201f24d. Unmodified download.

`locomotion.glb` — Universal Animation Library by Quaternius (https://quaternius.com), CC0. The demo retargets its
idle, walk, jog, sprint and jump clips onto the character at load.
